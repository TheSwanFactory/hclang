# REST Resource Design Record

Records are numbered in order. Each states its author, status and the records it
answers. Continue with `nn-Ernie-...`, `nn-Kiro-...` or `nn-Codex-...`.

01 is the implemented v0.57.0 public-read MVP, preserved from the former
`spec/a20-rest-resource.md` with relocated relative links. 02 is Kiro's saved
original issue body. 03–05 preserve GitHub reviews, the revised proposal and its
response. 06 recommends simplification; 07 is Kiro's response. 08 records the
accepted design and implementation status. Historical recommendations do not
become requirements merely by appearing here.

account; filenames distinguish their actual design/review authors. The original
a20 path remains a landing page. Issue #277 tracks the shipped MVP; #570 tracks
the extension. Design decisions belong in these records.
