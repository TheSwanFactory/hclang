# REST Resource Design Record

Records are numbered in order. Each states its author, status and the records it
answers. Continue with `nn-Ernie-...`, `nn-Kiro-...` or `nn-Codex-...`.

Historical proposals and reviews are preserved with their own status and
sources. A recommendation is not an accepted requirement merely because it
appears here. The original public-read MVP retains its text with relocated
relative links; subsequent records identify captured sources and accepted
changes.

Attribution follows Ernie's requested naming scheme. GitHub comments share one
account; filenames distinguish their actual design/review authors. The original
a20 path remains a landing page. Issue #277 tracks the shipped MVP; #570 tracks
the extension. Design decisions belong in these records.
